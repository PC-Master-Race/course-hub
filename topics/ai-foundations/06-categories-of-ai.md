<p>Quick Distinction: Bots vs. Agents</p>

<p>Now that you know the five categories, there is one more vocabulary distinction worth knowing</p>

<p>Before we go further -- the difference between a bot and an AI agent. You will hear both terms in</p>

<p>The workplace, and they are not the same thing.</p>

<p>Bot AI Agent</p>

<p>How it works Follows fixed rules -- if X</p>

<p>Happens, do Y.</p>

<p>Reasons, plans, and decides</p>

<p>What to do next.</p>

<p>Flexibility Rigid -- can only handle what it</p>

<p>Was programmed for.</p>

<p>Flexible -- adapts based on</p>

<p>Context and goals.</p>

<p>Example A chatbot that answers the</p>

<p>Same 10 FAQ questions.</p>

<p>An AI that researches a topic,</p>

<p>Drafts a report, and emails it.</p>

<p>Workplace signal You set it up once and it runs on</p>

<p>Autopilot.</p>

<p>You give it a goal and it figures</p>

<p>Out the steps.</p>

<p>Why This Matters for You</p>

<p>-- Most tools you have used so far in this course are closer to bots -- powerful, but rule-based.</p>

<p>-- AI agents are the next frontier -- tools that can handle multi-step tasks on your behalf.</p>

<p>-- a later lesson will go deeper into agents and the important ethical questions they raise.</p>

<p>-- For now: if a tool asks for a goal and handles the steps itself, you are working with an agent.</p>

<h3>Part 2: Scoped AI -- Helpful, But It Stays in Its Lane</h3>

<p>Have you ever used a chat box on a company website to ask a question? Maybe it helped you</p>

<p>Track a package or find store hours. But when you asked something a little different -- something</p>

<p class="standout-question">It was not set up for -- it said 'I don't understand' or sent you to a human?</p>
<p>That is a scoped AI. It is set up to handle a specific set of topics. It will not go outside that area,</p>

<p>Even if it is powered by a smart AI model underneath.</p>

<p>Important: many of these tools today use real AI -- the same kind as ChatGPT. They can</p>

<p>Understand how you talk and give natural answers. But they are still limited to one topic or</p>

<p>Product on purpose. That limit is a design choice -- not a sign that the tool is weak.</p>

<p>Definition: Scoped AI</p>

<p>A scoped AI tool stays inside a set area -- a topic, a product, a company's rules. It waits for</p>

<p>You to start the conversation. It answers your question. Then it stops. It does not go look for</p>

<p>Other problems to solve. It does not connect to other tools on its own. Modern examples:</p>

<p>Intercom, Zendesk AI, and bots built on Playlab.ai.</p>

<h3>Part 3: Autonomous Agents -- You Give the Goal, It Does the Work</h3>

<p>Think about a really capable coworker. You walk up to them on Monday and say: 'Can you find</p>

<p>The three best vendors for our supply order, compare their prices, write up a one -page</p>

<p>Summary, and email it to the team by noon?' Then you walk away.</p>

<p>A good coworker can do that. They will figure out the steps themselves. They will use whatever</p>

<p>Tools they need -- the internet, a spreadsheet, email. They will handle small problems along the</p>

<p>Way. And they will come back to you with the finished result.</p>

<p>An AI agent works the same way. You give it a goal. It plans the steps. It uses tools. It finishes</p>

<p>The job. You review the result at the end.</p>

<p>This is not a future idea -- it is happening right now. Microsoft Copilot, tools built on OpenAI's</p>

<p>Technology, and platforms like AutoGPT are being used in real workplaces today, in healthcare,</p>

<p>Marketing, and HR.</p>

<p>Definition: Autonomous Agent</p>

<p>An autonomous agent is an AI tool that receives a goal from you and then plans and</p>

<p>Completes the steps on its own. It can use multiple tools -- like search, email, or a document</p>

<p>Editor -- all in one task. It can also adjust its plan if something goes wrong. You review the</p>

<p>Final result, not every single step.</p>

<p>How an Agent Gets a Task Done -- Step by Step</p>

<p>Here is what happens when you give a goal to an AI agent. This is what makes it different from</p>

<p>Every other AI tool you have used so far.</p>

<p>Step What the Agent Does Why This Is Different</p>

<p>Need in plain language.</p>

<p>You do not write code or set up</p>

<p>Rules. Just talk to it like a</p>

<p>Person.</p>

<p>Step 2: Make a Plan The agent breaks your goal into</p>

<p>Smaller steps.</p>

<p>You do not have to list them.</p>

<p>Step 3: Choose Tools The agent picks which tools to</p>

<p>Use -- search, email, a</p>

<p>Spreadsheet, a document editor.</p>

<p>One agent can use many tools</p>

<p>In the same task.</p>

<p>Step 4: Do the Work The agent completes each step</p>

<p>And checks its own result before</p>

<p>Moving on.</p>

<p>It is reviewing its own work as it</p>

<p>Goes.</p>

<p>Agent tries a different approach.</p>

<p>A scoped tool would just stop.</p>

<p>An agent keeps going.</p>

<h3>Part 5: More Power Means More Responsibility</h3>

<p>Here is the important thing to understand: the more an AI tool can do on its own, the more</p>

<p>Carefully you need to watch it.</p>

<p>A scoped AI that sends the wrong message does it once. You can see it. You can fix it. An</p>

<p>Autonomous agent might send emails, update records, and trigger other actions before you ever</p>

<p>Look at what it did. A small mistake early in the process can turn into a bigger problem by the</p>

<p>End.</p>

<p>This does not mean agents are bad. It means they require more careful oversight. More power</p>

<p>Needs more attention, not less.</p>

<p>What Can Go Wrong How to Stay in Control</p>

<p>A small mistake in step 2 can affect every step</p>

<p>After it.</p>

<p>Always check the final result. A clean-looking</p>

<p>Output does not mean every step was correct.</p>

<p>If your goal is vague, the agent will guess what</p>

<p>You meant. It might guess wrong.</p>

<p>Be specific. The RTCF framework you learned</p>

<p>Still works -- use it with agents too.</p>

<p>The agent might take an action you did not expect</p>

<p>-- like sending an email or changing a file.</p>

<p>Start with read-only access. Only let the agent</p>

<p>Take real actions once you trust how it works.</p>

<p>The output might sound confident and well-written</p>

<p>But still contain mistakes.</p>

<p>Check the facts. Good writing does not mean</p>

<p>Correct information. Lesson 7 still applies here.</p>

<p>The agent might affect real people -- customers,</p>

<p>Coworkers -- without a human reviewing first.</p>

<p>Build in a review step before any agent action</p>

<p>Goes out to real people.</p>
